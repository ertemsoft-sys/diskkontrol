# Üçüncü taraf yazılımlar

Disk Kontrol aşağıdaki üçüncü taraf bileşenleri kullanır.

## OpenSSL 1.0.2u

E-postanın SSL/TLS ile gönderilmesi için programla birlikte `libeay32.dll` ve
`ssleay32.dll` dağıtılır. Dosyalar Indy projesinin resmi deposundan alınmıştır:
<https://github.com/IndySockets/OpenSSL-Binaries> (`openssl-1.0.2u-x64_86-win64.zip`).

This product includes software developed by the OpenSSL Project for use in
the OpenSSL Toolkit (<https://www.openssl.org/>).

This product includes cryptographic software written by Eric Young
(eay@cryptsoft.com). This product includes software written by
Tim Hudson (tjh@cryptsoft.com).

OpenSSL 1.0.2, OpenSSL License ve özgün SSLeay License altında dağıtılır.
Lisans metninin tamamı: <https://www.openssl.org/source/license-openssl-ssleay.txt>

## Indy (Internet Direct)

SMTP bağlantısı için Delphi ile birlikte gelen Indy bileşenleri kullanılır.
Indy, Indy Modified BSD License altında dağıtılır: <https://www.indyproject.org/license/>

## Embarcadero Delphi VCL

Program Embarcadero Delphi ile derlenmiştir. VCL çalışma zamanı ve
"Cobalt XEMedia" VCL stili Embarcadero lisansı kapsamında dağıtılabilir
(redistributable) bileşenlerdir.
